Pour que JARVIS accepte cette extension, collez ci-dessous le jeton affiché dans JARVIS : Paramètres › Sécurité › Extension navigateur. Sans jeton, JARVIS l'ignore.

Sur ces sites (sous-domaines compris), JARVIS ne peut ni lire la page, ni cliquer, ni taper, ni gérer l'onglet.
