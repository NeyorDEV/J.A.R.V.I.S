━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ Heure & Date ]
  - Quelle heure est-il ? -> Donne l'heure locale actuelle de votre système
  - On est quel jour ? / Quelle date ? / Quel jour sommes-nous ? -> Date complète du jour
  - C'est quel mois ? / Quelle année ? -> Mois ou année en cours
  - J'ai quel âge ? -> Calcule automatiquement votre âge actuel basé sur votre date de naissance (21 mai 1988)

[ Système PC ]
  - État de la batterie / Niveau de charge / Autonomie -> Niveau de charge et si le PC est branché
  - CPU / Charge du processeur / Utilisation RAM / Mémoire vive -> État de santé matériel du PC en temps réel
  - Allumé depuis combien de temps ? / Uptime -> Temps écoulé depuis le dernier démarrage du PC
  - Volume monte / baisse / coupe (Mute) -> Contrôle matériel pas-à-pas du volume Windows
  - Volume à [X]% / Son à [X]% -> Règle précisément le volume Windows au pourcentage demandé
  - Remets le son / Unmute -> Réactive le volume système s'il était coupé
  - Prends un screenshot / Capture d'écran -> Capture l'écran et sauvegarde automatiquement le fichier image sur votre Bureau
  - Éteins le PC / Arrête le PC / Shutdown [dans X secondes/minutes] -> Éteint proprement votre PC (avec option de délai)
  - Redémarre le PC / Reboot [dans X secondes/minutes] -> Redémarre le PC (avec option de délai)
  - Mets le PC en veille / Mode veille / Sleep [dans X secondes/minutes] -> Suspend l'activité du PC (avec option de délai)
  - Verrouille le PC / Verrouille la session / Lock le PC -> Verrouille instantanément la session utilisateur Windows (délai de 5s)
  - Annule l'arrêt / Annule le redémarrage / Annule la veille -> Annule immédiatement une commande de mise hors tension ou veille planifiée
  - Vide la corbeille / Nettoie la corbeille -> Efface définitivement tous les fichiers de la corbeille Windows de façon silencieuse

[ Gestion des Fichiers & Dossiers ]
  - Ouvre mon [Bureau / Documents / Téléchargements / Images / Musique / Vidéos] -> Accès direct aux dossiers système
  - Ouvre le dossier [Nom] / Ouvre le fichier [Nom] -> Recherche et ouverture intelligente d'un répertoire ou d'un document local
  - Range mes dossiers / Mosaïque dossiers -> Organisation spatiale des fenêtres d'explorateur
  - Trie mes fichiers par [Type / Date] -> Classement des fichiers du dossier actif par catégorie ou chronologie
  - Trie complet -> Range tous les fichiers par type puis par date à l'intérieur de chaque répertoire
  - Crée le dossier [Nom] / Renomme [Ancien] en [Nouveau] -> Gestion à chaud de l'arborescence locale
  - Déplace [Fichier] vers [Destination] -> Déplacement physique de fichiers
  - Analyse le fichier [Nom] -> Lecture, extraction et résumé intelligent du contenu textuel par l'IA

[ Applications & Jeux ]
  - Ouvre / Lance [Calculatrice / Notepad / Paint / Chrome / Firefox / Edge / Opera] -> Lancement d'applications courantes
  - Ouvre / Lance [Steam / Origin / EA App / Gestionnaire de tâches] -> Lancement de plateformes de jeux ou d'utilitaires
  - Ferme / Quitte [Nom de l'application] -> Fermeture propre de la fenêtre ciblée par son processus
  - Mode Boulot ! -> Lance votre environnement complet de travail (Claude, Outlook, Chrome, Spotify)
  - Mode Gaming / On joue ! -> Optimise le système et lance la plateforme de jeu préférée
  - On joue à Rocket League -> Lance directement le jeu Rocket League sur votre PC

  - Active / Désactive l'accélération graphique / Boost le GPU -> Performance 3D Three.js
  - Active les sous-titres / Désactive le texte -> Bascule l'affichage textuel de la parole sur le HUD
  - Active le clavier / Ferme le clavier -> Module de saisie de commandes écrites
  - Ferme la recette / Masque la recette -> Fermeture des fiches cuisine actives

  - Active / Désactive le mode AR -> Hand-tracking webcam et contrôle gestuel à distance sans contact

[ Minuteurs Interactifs (HUD) ]
  - Mets un minuteur de [X] minutes / Lance un timer de [X] minutes -> Démarre un compte à rebours et l'affiche sur le HUD
  - Ajoute [X] minutes au minuteur / Rallonge le timer de [X] minutes -> Augmente dynamiquement la durée du minuteur actif
  - Retire [X] minutes au minuteur / Diminue le timer de [X] minutes -> Réduit la durée du minuteur en cours d'exécution
  - Annule le minuteur / Arrête le minuteur / Stop le chrono -> Arrête immédiatement le compte à rebours et l'efface du HUD
  - Combien de minuteurs actifs ? / Combien de temps reste-t-il ? -> Affiche l'état et le nombre de minuteurs en cours

[ Mode Hologramme 3D - Gestes & Commandes ]
  - *Balayage Main (Swipe Gauche/Droite)* -> Fait défiler les formes géométriques 3D actives (Sphère, Cube, Tore, Cône...)
  - *Balayage avec 2 Mains* -> Efface instantanément toutes les formes de la scène (CLR)
  - *Main Ouverte* -> Déclenche une explosion de particules de lumière cyan et détruit la forme Three.js ciblée
  - *Poing Fermé* -> Compresse et déforme la figure 3D active (effet de compression gravitationnelle)
  - *Serrer Index + Pouce (Pinch 1 Main)* -> Attrape un sommet de la figure 3D pour étirer et sculpter sa géométrie en temps réel
  - *Serrer Index + Pouce (Pinch 2 Mains)* -> Permet de translater, d'appliquer un zoom orbital (Scale) et de tourner la figure dans l'espace
  - *Bouton "JEU" (Interface)* -> Lance ou arrête le jeu de briques holographique (fais rebondir la balle physique avec ta main !)
  - *Bouton "CLR" (Interface)* -> Supprime toutes les figures géométriques de la scène d'un seul clic
  - *Raccourcis Clavier* :
    - Touches [1-9] -> Génère instantanément une forme (1: Sphère, 2: Cube, 3: Cylindre, 6: Octaèdre, 7: Tore, 8: Noeud ADN...)
    - Touche [Delete / Backspace] -> Efface la scène
    - Touche [R] -> Réinitialise la déformation de la figure ciblée

[ Explorateur de Fichiers Spatial 3D (Hologramme) ]
  - Ouvre mes dossiers / Explorateur 3D / Mode explorer / Affiche mes fichiers / Ouvre l'explorateur spatial -> Déploie l'explorateur de fichiers spatial 3D en hologramme
  - *Clic Gauche / Pincement Main sur un Dossier (Cube)* -> Entre dans le dossier et l'affiche au centre en 3D concentrique
  - *Clic Gauche / Pincement Main sur un Fichier (Sphère)* -> Ouvre le fichier avec son application par défaut sur le PC
  - *Clic Gauche / Pincement Main sur la Pyramide Jaune (Retour)* -> Dépile l'arborescence et remonte au dossier parent en 3D
  - *Clic Gauche / Pincement Main sur la Corbeille (Tore Rouge)* -> Ouvre le dossier de la Corbeille Windows en 3D concentrique
  - *Glisser-Déposer (Drag & Drop) Souris ou Main* :
    - Fichier/Dossier sur un dossier -> Déplace l'élément dans ce sous-dossier (avec indexation intelligente et sans doublon)
    - Fichier/Dossier sur le bouton RETOUR (ou sur le parent en périphérie) -> Remonte l'élément d'un niveau dans l'arborescence
    - Fichier/Dossier sur la Corbeille -> Envoie l'élément à la Corbeille Windows native (ou le supprime définitivement si déjà dans la Corbeille)
    - Déplacer un élément hors de la Corbeille vers le dossier parent -> Restaure le fichier avec son nom et son extension d'origine préservés
  - *Glisser Clic Gauche en zone vide (Souris)* -> Translation (panning) de toute la scène 3D pour naviguer confortablement
  - *Glisser Clic Droit (Souris)* -> Rotation orbitale tridimensionnelle complète (spin) pour observer l'hologramme sous tous les angles

[ Carte Domotique 3D de la Maison (Hologramme) ]
  - Jarvis, affiche ma maison / Carte domotique / Mode carte 3D / Affiche la carte 3D / Ma maison 3D -> Déploie la maquette 3D interactive et dynamique de la maison
  - *Interaction tactile ou geste* -> Permet d'allumer/éteindre ou changer l'intensité/couleur des lumières et prises connectées directement en 3D
  - *Glisser Clic Gauche en zone vide (Souris)* -> Déplacement latéral (translation) dans l'environnement 3D de la maquette
  - *Glisser Clic Droit (Souris)* -> Rotation orbitale complète de la structure de la maison 3D

[ Cortex Neuronal 3D - Constellation de la Mémoire (Hologramme) ]

  - *Bouton "SUPPRIMER" du Panel* -> Supprime définitivement le souvenir à chaud de la base de données (ChromaDB ou jarvis_memoire.json) avec effet de désintégration 3D et de propagation d'onde lumineuse (Ripple)
  - *Sparks & Synapses* -> Visualisation dynamique de signaux électriques circulant à travers les connexions synaptiques actives
  - *Glisser Clic Gauche en zone vide (Souris)* -> Déplacement de la constellation dans l'espace 3D
  - *Glisser Clic Droit (Souris)* -> Rotation de la structure neuronale tridimensionnelle

[ Capacités Spéciales de l'Autopilote ]
  - *Filtrage Anti-Publicité* -> JARVIS filtre automatiquement les annonces sponsorisées et carrousels publicitaires sur Amazon pour ne cliquer que sur de vrais articles organiques.
  - *Sélection par Index Visuel* -> Utilise un sélecteur universel `[item-number=N]` pour repérer de manière infaillible le Nième article réellement visible à l'écran, sans se laisser induire en erreur par les décalages d'index.
  - *HUD Diagnostic en Temps Réel* :
    - Génère une bannière cybernétique `#jarvis-hud-banner` en haut de l'écran affichant les logs et l'étape d'autopilote en cours.
    - Encadre en vert fluo néon (`3px solid #00ffaa`) les éléments de saisie et les articles sur lesquels le curseur virtuel s'apprête à cliquer.
  - *File d'Attente Anti-Collision (Queue)* -> Enchaîne de façon fluide des séquences complexes de clics, saisies clavier simulées (à 100ms/caractère) et de focus.
  - *Persistance inter-pages* -> L'autopilote survit aux rechargements de page (soumission de formulaires) grâce à un stockage local temporaire persistant.
