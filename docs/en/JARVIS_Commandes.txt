+----------------------------------------------------------+
          J.A.R.V.I.S - Complete Commands Guide
+----------------------------------------------------------+

The commands below are given in English (translated from the French reference, docs/fr/JARVIS_Commandes.txt). JARVIS understands them in English mode: see the "LANGUAGE" section at the end of the document
("switch to English" / "passe en français" to go back). Square brackets [ ] indicate a variable part of the phrase.

[ Time & Date ]
  - What time is it? -> Gives your system's current local time
  - What day is it? / What date is it? / What day are we? -> Today's full date
  - What month is it? / What year is it? -> Current month or year
  - How old am I? -> Automatically calculates your current age based on your date of birth (May 21, 1988)

[ PC System ]
  - Battery status / Battery level / Battery life -> Battery level and whether the PC is plugged in
  - CPU / Processor load / RAM usage / Memory -> Real-time PC hardware health status
  - How long has it been on? / Uptime -> Time elapsed since the last PC startup
  - Volume up / down / mute -> Step-by-step hardware control of Windows volume
  - Volume to [X]% / Sound to [X]% -> Precisely sets the Windows volume to the requested percentage
  - Turn sound back on / Unmute -> Re-enables system volume if it was muted
  - Take a screenshot / Screen capture -> Captures the screen and automatically saves the image file to your Desktop
  - Turn off the PC / Shut down the PC / Shutdown [in X seconds/minutes] -> Cleanly shuts down your PC (with delay option)
  - Restart the PC / Reboot [in X seconds/minutes] -> Restarts the PC (with delay option)
  - Put the PC to sleep / Sleep mode / Sleep [in X seconds/minutes] -> Suspends PC activity (with delay option)
  - Lock the PC / Lock the session / Lock PC -> Instantly locks the Windows user session (5s delay)
  - Cancel shutdown / Cancel restart / Cancel sleep -> Immediately cancels a scheduled power-off or sleep command
  - Empty the Recycle Bin / Clean the Recycle Bin -> Permanently deletes all files from the Windows Recycle Bin silently

[ File & Folder Management ]
  - Open my [Desktop / Documents / Downloads / Pictures / Music / Videos] -> Direct access to system folders
  - Open folder [Name] / Open file [Name] -> Smart search and opening of a local directory or document
  - Organize my folders / Tile folders -> Spatial arrangement of File Explorer windows
  - Sort my files by [Type / Date] -> Sorting active folder files by category or chronology
  - Full sort -> Organizes all files by type then by date inside each directory
  - Create folder [Name] / Rename [Old] to [New] -> On-the-fly management of the local directory tree
  - Move [File] to [Destination] -> Physical moving of files
  - Analyze file [Name] -> Reading, extraction, and smart summarization of text content by AI

[ Applications & Games ]
  - Open / Launch [Calculator / Notepad / Paint / Chrome / Firefox / Edge / Opera] -> Launching common applications
  - Open / Launch [Steam / Origin / EA App / Task Manager] -> Launching gaming platforms or utilities
  - Close / Quit [Application Name] -> Clean closing of the target window by its process
  - Work Mode! -> Launches your complete work environment (Claude, Outlook, Chrome, Spotify)
  - Gaming Mode / Game on! -> Optimizes the system and launches your favorite gaming platform
  - Let's play Rocket League -> Directly launches the Rocket League game on your PC

  - 3D views (file explorer, house, cortex, chess, network radar) open directly via voice, one at a time
  - Close cortex / Close the house / Close space explorer / Close radar / Close 3D view / Back Jarvis -> Closes the open 3D view and returns to the JARVIS interface
  - *"⌂ BACK TO JARVIS" button* -> Same effect, using the mouse
  - *Hand control (webcam)* -> Pinch (index + thumb) to grab or move, two pinched hands to rotate; a pinch on a button clicks it
  - *Circular index finger gesture* -> Mutes / unmutes the JARVIS microphone

[ 3D Spatial File Explorer ]
  - 3D Explorer / Spatial Explorer / Show spatial explorer / Explorer mode -> Deploys the 3D spatial file explorer ("my folders" / "my files" open Windows Explorer)
  - *Left Click / Hand Pinch on a Folder (Cube)* -> Enters the folder and displays it at the center in concentric 3D
  - *Left Click / Hand Pinch on a File (Sphere)* -> Opens the file with its default application on the PC
  - *Left Click / Hand Pinch on the Yellow Pyramid (Back)* -> Pops the directory tree and goes up to the parent folder in 3D
  - *Left Click / Hand Pinch on the Recycle Bin (Red Torus)* -> Opens the Windows Recycle Bin folder in concentric 3D
  - *Mouse or Hand Drag & Drop*:
    - File/Folder onto a folder -> Moves the item into this subfolder (with smart indexing and no duplicates)
    - File/Folder onto the BACK button (or onto the parent on the periphery) -> Moves the item up one level in the tree
    - File/Folder onto the Recycle Bin -> Sends the item to the native Windows Recycle Bin (or permanently deletes it if already in the Bin)
    - Moving an item out of the Recycle Bin to the parent folder -> Restores the file preserving its original name and extension
  - *Left Click & Drag in empty space (Mouse)* -> Panning of the entire 3D scene for comfortable navigation
  - *Right Click & Drag (Mouse)* -> Full 3D orbital rotation (spin) to inspect the scene from all angles

  - *Right Click & Drag (Mouse)* -> Full orbital rotation of the 3D house structure

[ 3D Neural Cortex - Memory Constellation ]

  - *"DELETE" Button on Panel* -> Permanently deletes the memory live from the database (ChromaDB or jarvis_memoire.json) with 3D disintegration effect and ripple light wave
  - *Sparks & Synapses* -> Dynamic visualization of electrical signals traveling through active synaptic connections
  - *Left Click & Drag in empty space (Mouse)* -> Movement of the constellation in 3D space
  - *Right Click & Drag (Mouse)* -> Rotation of the three-dimensional neural structure

[ 3D Chess Game ]

[ 3D Earth Globe ]
  - Show the Earth / Terrestrial globe / View from space -> Displays the 3D Earth globe, recentered, slowly rotating
  - Zoom in / Move closer / Closer (globe open) -> Moves the camera closer; below a certain altitude, switches to the 2D satellite map
  - Zoom out / Move away / Further (globe open) -> Moves the camera away (and exits the 2D map)
  - Show me / Fly over / Fly to / Zoom in on [Location, city, country] -> Flies to the destination (higher for a country, lower for a city)
  - Show my location / Where am I? / Locate me -> Flies over the city configured in JARVIS (otherwise, browser geolocation)
  - Route from [City A] to [City B] / Journey from [A] to [B] -> Plots the route (great-circle) between two cities and frames it
  - Close the map / Close the globe / Back to JARVIS -> Closes the globe and returns to the main interface

Not yet installed: JARVIS asks whether to install it from the latest GitHub release (yes / no, by voice or click); a newer version exists: prompts for update

[ Autopilot Special Capabilities ]
  - *Ad Filtering* -> JARVIS automatically filters out sponsored ads and promotional carousels on Amazon to click only on genuine organic items.
  - *Visual Index Selection* -> Uses a universal selector `[item-number=N]` to reliably identify the Nth item actually visible on screen, without getting misled by index offsets.
  - *Real-Time Diagnostic HUD* :
    - Generates a `#jarvis-hud-banner` cybernetic banner at the top of the screen showing logs and the current autopilot step.
    - Outlines input elements and items the virtual cursor is about to click in neon green (`3px solid #00ffaa`).
  - *Anti-Collision Queue* -> Smoothly chains complex sequences of clicks, simulated keystrokes (at 100ms/character), and focus events.
  - *Cross-page persistence* -> The autopilot survives page reloads (form submissions) thanks to persistent temporary local storage.

    → Directly opens the Downloads folder on Windows and places the virtual cursor there.
